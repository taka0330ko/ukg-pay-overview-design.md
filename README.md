# UKG Pay Overview — design.md Comparison

[English](#english) | [日本語](#日本語)

## English

This repository compares how the level of detail in design.md—and subsequent AI revisions prompted in natural language—affects the implementation of a Figma design.

### Versions

| Version | Approach and conditions | Implementation | Live URL |
| --- | --- | --- | --- |
| v1 | An effortless design and implementation workflow in Codex, using Figma MCP and a design.md generated by the [design-md-figma](https://github.com/bergside/design-md-figma) plugin. | [v1 branch](https://github.com/taka0330ko/ukg-pay-overview-design.md/tree/v1) | To be added |
| v2 | Uses Figma MCP and the same plugin, with design.md also explicitly specifying libraries, the technology stack, and detailed interactive behavior. | [v2 branch](https://github.com/taka0330ko/ukg-pay-overview-design.md/tree/v2) | To be added |
| v3 | Builds on v2 with AI revisions requested through natural-language instructions. | [v3 branch](https://github.com/taka0330ko/ukg-pay-overview-design.md/tree/v3) | To be added |

### Comparison goals

- **v1 vs. v2:** Evaluate how specifying technologies and behavior in greater detail in design.md affects visual and interaction fidelity.
- **v2 vs. v3:** Evaluate how additional natural-language revision instructions improve the implementation.

Compare appearance (layout, spacing, typography, and colors) and interactive behavior (switching, expanding/collapsing, and selection) under the same viewing conditions.

### Branch roles

- `main`: An overview of the comparison goals, implementation conditions, and links to each version.
- `v1` / `v2` / `v3`: Separate implementations preserved for individual deployment and comparison.

Each implementation branch includes Vercel configuration. Live URLs will be added to the table after deployment is confirmed.

The initial implementation files currently remain on main as well. Use the version branches for comparisons.

## 日本語

Figmaから画面を実装する際に、design.mdに記載する情報の詳しさと、その後の自然言語によるAIへの修正指示が、実装結果にどう影響するかを比較するリポジトリです。

### バージョン

| バージョン | 作成方法・条件 | 実装 | 公開URL |
| --- | --- | --- | --- |
| v1 | CodexでFigma MCPと[design-md-figma](https://github.com/bergside/design-md-figma)プラグインが生成したdesign.mdを使った、手間をかけない（effortlessな）設計・実装。 | [v1ブランチ](https://github.com/taka0330ko/ukg-pay-overview-design.md/tree/v1) | 未記載 |
| v2 | Figma MCPと同プラグインに加え、design.mdに使用ライブラリ・技術スタック・細かなインタラクションの挙動も明記した実装。 | [v2ブランチ](https://github.com/taka0330ko/ukg-pay-overview-design.md/tree/v2) | 未記載 |
| v3 | v2をベースに、自然言語の指示でAIに修正させた実装。 | [v3ブランチ](https://github.com/taka0330ko/ukg-pay-overview-design.md/tree/v3) | 未記載 |

### 比較の目的

- **v1とv2：** design.mdで技術や挙動を詳しく指定した場合に、見た目や動作の再現度がどう変わるかを確認する。
- **v2とv3：** 自然言語による追加の修正指示で、実装がどう改善されるかを確認する。

見た目（レイアウト・余白・文字・色）と、操作時の動作（切り替え・開閉・選択など）を同じ画面条件で比較します。

### ブランチの役割

- `main`：比較の目的・作成条件・各版へのリンクをまとめる案内。
- `v1` / `v2` / `v3`：各バージョンの実装を保存し、個別に公開するためのブランチ。

各実装ブランチにはVercel用の設定を含めています。公開URLはデプロイ確認後に上の表へ追記します。

現時点では、mainにも初回実装のファイルが残っています。比較対象には各バージョンのブランチを使用してください。
